## Sushi Avenue Bot

Простой Telegram-бот для просмотра меню суши/роллов/маков. Показывает категории, отправляет фото из сайта и описания, работает на библиотеке `pyTelegramBotAPI`.

### Требования
- Python 3.10+ (проверено на 3.12)
- pip

### Установка
1) Клонируйте проект или скачайте архив.
2) Создайте и активируйте виртуальное окружение (опционально):
   - `python -m venv venv`
   - Windows PowerShell: `.\venv\Scripts\Activate.ps1`
3) Установите зависимости:
   - `pip install pytelegrambotapi python-dotenv`

### Настройка окружения
1) Создайте файл `.env` в корне проекта.
2) Добавьте токен бота от BotFather:
   - `TOKEN=ваш_telegram_token`

### Запуск
- `python sushi_bot_v1.py`

После запуска бот начинает polling и отвечает на команды:
- `/start` — показывает главное меню (роллы/маки/суши).
- Выбор позиций отправляет фото и краткое описание.
- Кнопка «Назад в главное меню» возвращает к категориям.

### Структура
- `sushi_bot_v1.py` — основной код бота.
- `media/photo/` — примеры изображений (используются внешние URL, но папка может пригодиться для локальных фото).

### Полезно знать
- Логи пишутся в stdout (удобно смотреть в консоли).
- Если Telegram блокирует внешние картинки, замените URL на локальные файлы и передавайте `photo=open(path, "rb")`.
